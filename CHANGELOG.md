## [Unreleased]

### Added
- Initial release of Miqati prayer times application
- Accurate prayer times calculation using Adhan library
- Qibla compass with magnetic declination correction
- Location detection (GPS and manual input)
- Adhan audio playback with foreground service
- Prayer notifications with AlarmManager
- Support for multiple calculation methods
- Support for different madhabs (Shafi, Hanafi)
- Light and Dark theme support
- Full RTL and Arabic language support
- Hijri date display
- Live countdown to next prayer
- Clean Architecture with MVVM pattern
- Jetpack Compose UI with Material 3
- Offline-first design (no internet required after setup)
- Privacy-focused (no analytics, no tracking)
- Unit tests for core calculations
